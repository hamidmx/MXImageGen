i Generation Mode: New — one original image
  • Your text is never sent raw. It is wrapped into a structured prompt rebuilt for the selected Drawing Model, with your words kept as the core instruction.
  • The model is asked for a brand-new, original image. No source picture is attached.
  • The Reference image (orange button, max 1) is described as a style guide only — its colours, technique and look are copied, not its subject.
  • Aspect Ratio is applied as the authoritative output shape and overrides any ratio you typed in the text.
  • Generation per image sends that many independent requests, so variations differ genuinely. Browse them with the ‹ › arrows on the result.
  • Results are named gen_<Model>_1, with extra variations as -2, -3.
 Generation Mode: Edit — recreate the images you attach
  • Your text becomes the editing instruction, wrapped into a structured prompt for the selected Drawing Model.
  • Images to edit (blue button, up to 20) are sent one request per image, so each one gets its own result box. Their file names are named in the prompt.
  • Each image is recreated while keeping its subject and composition recognisable, unless your instruction says otherwise.
  • The Reference image (orange button, max 1) is a style guide only — its look is copied, not its subject.
  • Aspect Ratio is the authoritative output shape and overrides any ratio you typed.
  • Generation per image multiplies the requests: 5 images × 3 = 15 requests.
  • Results keep each source file's name, with extra variations as -2, -3.
 Generation Mode: New Bulk Images — one image per CSV row
  • Variables are always UPPERCASE and always start with VAR_ — e.g. {VAR_MAIN_SUBJECT}, {VAR_TITLE}. Both {…} and {{…}} braces work. Anything else in braces is left untouched, so ordinary text is safe.
  • Your CSV's header row uses those same VAR_ names. Extra columns such as # are kept for reference but never substituted.
  • Click the green Upload data file button (enabled once a prompt is typed) and pick one .csv. Every row after the header is one image.
  • Nothing is sent until the file is checked: each VAR_ placeholder needs a matching column and at least one non-empty row. Problems are reported precisely and generation is blocked.
  • Generate opens a preview of the file where you tick exactly which entries to run. Select all / Clear help; rows already generated in this session are tinted green but can be re-run.
  • Each chosen row becomes its own rebuilt prompt with that row's exact values — 10 rows = 10 requests, and 30 with Generation per image = 3.
  • Outputs are named <#>_gen_<Model>_<first 10 chars of the first variable>, e.g. 14_gen_GPT_BabySeaTur.
